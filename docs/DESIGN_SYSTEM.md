# Дизайн-система QR-меню «Фуджи»

Единый источник правды по визуальным токенам. Значения взяты из действующего кода (новых цветов не вводилось);
близкие дубли сведены к одному (см. [§ 10](#10-что-сведено-и-что-осталось)).

## 0. Два контекста

| | Гостевое меню | Рабочие интерфейсы |
|---|---|---|
| Где | `menu-web/guest` (`app.css`, vanilla JS) | официант `menu-web/staff` (`staff.css`) и админка `menu-admin` (Nuxt 3 + Nuxt UI + Tailwind) |
| Бренд | Фуджи, фиолетовый `#993CA6` | тёмно-синий `#091027` + главное действие `#5A52D5` |
| Шрифт | Wix Madefor Display (400–700, свой сервер `/ui/fonts`) | Inter (400–700, Google Fonts) |
| Форма | мягкая, крупные радиусы (16–24), 14px базовый | плотная, 15px (официант) / Tailwind 14px (админка) |
| Токены живут | блок `:root` в начале `menu-web/guest/app.css` | официант: блок `:root` в начале `menu-web/staff/staff.css`; админка: `menu-admin/tailwind.config.ts` + `app.config.ts` |

Официант и админка — один язык: тот же `#091027`, `#5A52D5`, `#F5F4F9`, `#ECEBF2`, Inter. Гость — отдельный бренд;
пересечения случайны и там, где значения разные, это зафиксировано осознанно (§ 3).

Правила:

1. В CSS и в разметке не писать hex / `rgb()` / `font-size: Npx` — только `var(--…)` (проверка: `node scripts/check-tokens.mjs`).
2. Полупрозрачные цвета — через канал: `rgba(var(--ink-rgb), .3)`; в `:root` есть `--ink-rgb`, `--white-rgb`, `--purple-rgb` и др.
3. Новый цвет сначала добавляется в `:root` (и в этот документ) с понятным именем, потом используется.
4. В админке — классы Tailwind из палитр `brand / cta / accent / blush / cream / tag-*` и штатные `green / amber / red / slate`; произвольные `text-[11px]`, `bg-[#…]` не использовать.
5. Визуальная регрессия: `node scripts/visual-check.mjs` (§ 11).

## 3. Одноимённые токены гостя и официанта

Решение принято по смыслу: если значения разные потому что бренды разные — оставлены разными; одинаковые — сведены.

| Токен | Гость | Официант | Решение |
|---|---|---|---|
| `--bg` | `#F9F9F9` | `#F5F4F9` | **разные осознанно**: у официанта фон с сине-фиолетовым подтоном, он же `cream` админки |
| `--ink` | `#292929` | `#091027` | **разные осознанно**: гость — нейтральный графит, рабочие — фирменный тёмно-синий |
| `--muted` | `rgba(41,41,41,.5)` | `#7E7F83` | **разные осознанно** (производная от `--ink` / отдельный серый) |
| `--line` | `#CBCBCB` | `#ECEBF2` | **разные осознанно**: у гостя — граница, у официанта — фон полей (`blush`) |
| `--ok` | `#4F7947` (тёмно-зелёный текст на светлой подложке) | `#1E9E6A` (яркий зелёный) | **разные осознанно**: разные роли — текст статуса у гостя / индикатор у официанта |
| `--danger` | `#D8374B` | `#D8374B` | **одинаковые** (были одинаковы) |
| `--card` | `#FFFFFF` | `#fff` | **одинаковые** |
| `--shadow` | `0 0 14.2px rgba(0,0,0,.05)` | `0 0 14.2px rgba(0,0,0,.05)` | **одинаковые** |
| `--purple` / `--violet` | `#993CA6` | `#5A52D5` | разные бренды; в `staff.css` гостевой фиолетовый — `--guest-purple` (превью баннеров) |
| `--purple-soft` / `--guest-purple-soft` | `#F5ECF6` | `#F5ECF6` | одинаковые |
| `--warn` | нет (`--warn-soft/-ink`, `--kitchen`) | `#E08A00` | у гостя warn — только пара «подложка + текст» |

Слияние `--bg`, `--ink`, `--ok` в одно значение дало бы видимое изменение (цвет страницы, всех текстов, статусов), поэтому не делалось.
Админка отличается от официанта только в нейтралях и статусах: нейтрали — Tailwind `slate` (`muted` `#64748B` вместо `#7E7F83`),
статусы — Tailwind `green/amber/red`. Это допустимое расхождение: у админки собственная шкала Tailwind, а у официанта — плоский CSS.

## 4. Отступы

Шкала с шагом 4px; `--sp-N` = N × 4px — то же, что Tailwind `p-N` / `gap-N` / `m-N`.

| Токен | CSS-переменная | px | Tailwind |
|---|---|---|---|
| sp-1 | `--sp-1` | 4 | `p-1`, `gap-1` |
| sp-2 | `--sp-2` | 8 | `p-2` |
| sp-3 | `--sp-3` | 12 | `p-3` |
| sp-4 | `--sp-4` | 16 | `p-4` |
| sp-5 | `--sp-5` | 20 | `p-5` |
| sp-6 | `--sp-6` | 24 | `p-6` |
| sp-8 | `--sp-8` | 32 | `p-8` |
| sp-10 | `--sp-10` | 40 | `p-10` |
| sp-12 | `--sp-12` | 48 | `p-12` |

В `padding / margin / gap` всех трёх CSS-файлов значения на шкале заменены токенами. Значения вне шкалы (2, 3, 5, 6, 10, 14, 18 px, а также крупные 96/120) оставлены как есть:
это подгонка конкретных элементов (отступ иконки, высота пилюли), их слияние с соседним шагом меняло бы раскладку. `check-tokens.mjs` показывает их количество справочно.
